# Robot surface asset

`polymer-roughness.webp` is a 512 px grayscale roughness map for the robot's real-time physically based materials. It is not a flat picture of the robot. The moving components remain independent 3D geometry so their surfaces stay consistent throughout the full scroll-controlled turn.

Generated with the built-in imagegen tool, then resized and encoded to WebP with Sharp. Original: `exec-1b0c517a-583a-47e2-99f8-eb43fc3b222e.png`.

Generation prompt:

> Use case: product-mockup. Asset type: seamless grayscale roughness texture for a physically based real-time 3D robot, not a product photo. Primary request: a square, perfectly flat, edge-to-edge 1024 x 1024 scan-like texture of smooth manufactured polymer/acrylic surface microstructure. Medium gray base roughly RGB 170 with very fine low-contrast stochastic grain and a few extremely fine sparse handling hairline scratches in varied directions. Photorealistic microscopic finish; subtle and clean, manufactured new material with tiny real-world irregularities. Uniform neutral diffuse lighting across the whole tile. Seamlessly tileable with no visible edge boundaries. No objects, holes, borders, letters, labels, gradients, shadows, specular glare, large scratches, cracks, wood grain, fabric, embossed relief, dirt, vignette, or cartoon styling. Texture only; this will modulate roughness on black acrylic chassis and plastic parts in a 360-degree scroll-driven robot animation.

The geometry reconstructs the supplied kit photographs; it is not a dimensionally certified CAD model.
